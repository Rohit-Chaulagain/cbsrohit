01 — Roadmap

Eight steps from beginner to capable.

Each step explains what to study, what you should be able to do, and why that knowledge matters when you're defending or testing real systems.

Roadmap progress0 / 8
01

Computer fundamentals

2–4 days
⌄

Learn

  • Operating systems, files, processes and memory
  • Users, groups and permissions
  • How applications talk to the OS
  • Virtual machines and snapshots

You should be able to

  • Explain what a process is
  • Read basic system information
  • Understand why permissions matter
  • Run a Linux VM safely
Why it matters: malware, privilege escalation and persistence all make more sense once you understand processes, accounts and permissions.
02

Networking

1–2 weeks
⌄

Learn

  • IP addresses, subnets and routing
  • TCP vs UDP and ports
  • DNS, DHCP, ARP
  • HTTP/HTTPS, TLS and certificates
  • Firewalls, NAT and VPNs

Practice

  • Use ping, ipconfig/ifconfig, nslookup/dig and curl
  • Trace a request from your browser to a server
  • Capture traffic in Wireshark and identify DNS/HTTP/TLS
Why it matters: a huge part of security is understanding what normal network traffic looks like so you can spot what is abnormal.
03

Linux + command line

1 week
⌄

Learn

  • Filesystem navigation and permissions
  • Processes, services and logs
  • SSH and package management
  • grep, find, pipes and redirection

Practice commands

  • ls cd pwd cat grep find
  • chmod ps top kill
  • ssh curl wget
  • Read system and application logs
Why it matters: security tooling, servers, cloud systems and many SOC workflows rely heavily on Linux.
04

Python + scripting

1–2 weeks
⌄

Learn

  • Variables, loops, functions and files
  • Lists, dictionaries and error handling
  • JSON, APIs and HTTP requests
  • Regex basics

Build

  • Log parser
  • Simple port/service checker for your own lab
  • URL/status checker
  • Small automation scripts
Why it matters: scripting turns repetitive security work into repeatable workflows — useful in both blue-team and offensive roles.
05

Cybersecurity fundamentals

1 week
⌄

Learn

  • CIA triad
  • Authentication vs authorization
  • Encryption vs hashing
  • Vulnerabilities, threats and risk
  • Malware, phishing and social engineering

Understand the workflow

  • Asset → threat → vulnerability → impact
  • Prevention → detection → response → recovery
  • Least privilege and defense in depth
Why it matters: this gives you the vocabulary and mental model to understand almost every security topic that follows.
06

Hands-on labs

ongoing
⌄

Start with

  • TryHackMe beginner paths
  • OverTheWire for Linux basics
  • PortSwigger Web Security Academy
  • HTB Academy after the basics

Your goal

  • Read the scenario
  • Form a hypothesis
  • Run a command or test
  • Interpret the result
  • Write down what you learned
Why it matters: cybersecurity is an applied field. Labs are where concepts become muscle memory.
07

Choose a direction

after foundations
⌄
SOC / Blue Team

Logs, alerts, SIEM, detection, incident response and endpoint telemetry.

Web Security

HTTP, authentication, sessions, APIs, OWASP risks and secure development.

Penetration Testing

Recon, enumeration, vulnerability validation and reporting in authorized labs.

08

Build proof of skill

ongoing
⌄

Create

  • Lab write-ups
  • Small security scripts
  • Detection rules or log analysis notes
  • A simple home lab diagram

Show

  • What problem you solved
  • Your method
  • Evidence/screenshots
  • What you would improve next
Why it matters: a portfolio proves that you can think, investigate and communicate — not just that you watched a course.

04 — 90-day plan

A realistic first three months.

Consistency beats trying to “finish cybersecurity.” Aim for 60–90 focused minutes most days.

Days 1–30

Build the foundations

Computers, networking, Linux and the command line. Finish small exercises every day instead of binge-watching courses.

Days 31–60

Add security thinking

Security fundamentals, Python basics and beginner TryHackMe/OverTheWire rooms. Start documenting your mistakes.

Days 61–90

Go hands-on

Pick web security or SOC/blue team, complete practical labs and build 2–3 small portfolio projects.
